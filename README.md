# North Star Bakery

Branden Bellfield - Introduction to Web Development

This is my four-page bakery website for Touchstone 3. I added an external
CSS file to the HTML pages from Touchstone Task 2.

## Pages

- `index.html`: welcome, featured cookies, and visiting information
- `products.html`: breads, pastries, cakes, and prices
- `about.html`: the bakery story, team, and welcome audio
- `contact.html`: a practice request form, location, and hours

## Design

I used cream (#faf6ef), brown (#654331), dark brown (#352b26), and white
(#ffffff). Georgia is used for headings and Arial is used for other text.
All pages use `styles.css`.

The layout starts with stacked content for phones. A media query at 768px
uses Flexbox to place the header, featured item, team, and contact layout
in rows. Images and form fields fit their available space.
